# CSC 138 Network Lab

Interactive self-study companion for Sacramento State CSC 138-02, Fall 2026.

## Run locally

```bash
npm install
npm run dev
```

## Verify

```bash
npm run check
npm test
npm run build
```

The production build uses `/csc138/` as its public base path for deployment at
`https://dorkwitafork.github.io/csc138/`.

Student progress is stored in the browser under `csc138-progress-v1`. Chapter 1 content follows `Chapter1-Introduction.pdf`; later modules remain provisional until additional course materials are available.
